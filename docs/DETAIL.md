# 论文阅读

在 DSH 里给论文一个真正属于它的页面：整页阅读 PDF，自带缩放、翻页和高亮标注，选中看不懂的句子右击（或用浮动小工具条）直接问 DeepSeek，答案立刻显示在右侧栏里，不打断阅读。

## 怎么用

1. 点击左侧栏的「论文阅读」图标，打开独立阅读页。
2. 点击「打开 PDF」，或把 PDF 文件拖进页面（拖到页面任意位置都能打开）。
3. 打开过的论文会自动记在「历史阅读」里：空白页下方或顶部工具栏点「历史阅读」，右侧会列出读过的论文，点一条就能重新打开。
4. 用工具栏缩放（－ / 百分比 / ＋ / 适合宽度）和翻页（‹ / 页码输入 / ›）浏览论文。
5. 选中一段文字，旁边会浮出小工具条：**高亮 / 问 DeepSeek / 复制**。也可以直接右击，菜单里同样有这些操作。
6. 高亮会保存下来，关掉页面再打开同一份 PDF 仍然在；点击已有高亮可以问它或删除它。
7. 右侧栏显示选中的原文和流式回答，底部可以继续追问。回答里的数学公式会用 KaTeX 排版成真正的数学公式（上下标、分式、求和号等），不是 LaTeX 源码。

## 它是怎么工作的

- 页面用 PDF.js 渲染（随插件离线打包，不访问外网），并生成真正的文字层，所以选中、复制、跨行选择都和普通网页文字一样。
- 高亮不修改 PDF，也不改动文字层：选中范围被记录成「第几页 + 第几个文字片段 + 字符偏移」，重绘后用这些信息恢复高亮框，所以缩放、翻页、重新打开都能定位。高亮存在浏览器本地（按文件名、大小、页数区分）。
- 提问会把选中的原文、页码和问题发到插件自己的 Host 路由；Host 用你在 DSH 里配置的默认模型请求一次回答，再把文字流式返回面板。提问不写入任何会话记录。

## 已知限制

- 只支持 PDF 文件；扫描版 PDF（没有文字层）无法选中文字，标注和提问都只能按页进行。
- 跨页选择不能高亮（小工具条里的「高亮」会变灰），提问仍然可以。
- 高亮和阅读历史都只保存在当前浏览器里（历史用 IndexedDB 存 PDF 副本，最多 20 篇、单篇 60 MB，超出时不入历史），换机器或清缓存会丢失。
- 「历史阅读」里的条目可以单条移除，也可以清空；删除只是移出历史，不影响磁盘上的原文件。
- 模型被要求用 LaTeX（`$…$` / `$$…$$`）写公式，再由页面排版；如果模型没遵守，公式仍以可读的纯文本显示。宽公式在窄栏里可以横向滚动。
- 每次提问独立进行，不携带整篇论文；只有选中的片段、当前页正文和面板里的最近几轮问答会发给模型。
- 回答使用 DSH 当前默认模型；想换模型请在会话的模型选择里调整默认模型。
